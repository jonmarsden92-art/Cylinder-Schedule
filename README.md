# Cylinder Schedule Generator

Upload a manufacturing schedule (Excel/CSV) and get a cylinder schedule based on Door Pack.

## Run in GitHub Codespaces

1. Click the **Code** button → **Codespaces** → **Create codespace on main**.
2. Wait for the environment to build and Streamlit to start.
3. The app will open in a new browser tab.
4. Upload your file and download the result.

## Logic

- Door Pack 1 → `70mm double euro`
- Door Pack 2,3,4,5,6 → `45mm single half euro`
